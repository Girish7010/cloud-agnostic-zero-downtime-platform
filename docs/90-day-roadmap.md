# 90-day roadmap

- Days 1–15: confirm application contract; local cluster; Terraform provider boundaries; baseline deployment.
- Days 16–30: AWS foundation, remote state, secrets, registry, managed data services, security controls.
- Days 31–45: CI build-once/sign/scan and GitOps promotion; staging gates.
- Days 46–60: API canary, worker drain, migration rehearsal, rollback tests.
- Days 61–75: load/capacity tests, KEDA/HPA/node scaling, dashboards and alerts.
- Days 76–90: tenant rings, EU residency review, backup restore drill, cost optimization and operational handover.
